Chrome のブックマークを、カスタマイズ可能なビジュアルダッシュボードに。Speed Dial と既存のブックマークをワンクリックで切り替え、すべてのフォルダをタイトルや URL で検索し、リンクをグループに整理して、アイコン、ページのプレビュー、アイテムのカバー、オリジナル画像でタイルを自分好みに仕上げられます。

アカウント不要。広告なし。独自のブックマーク保存領域もありません。ブックマークは Chrome に残ります。

既存のブックマークを作り直すことなく、高速でカスタマイズできる新しいタブページを使いたい方に最適です。

2 つのモード、1 クリックで切り替え
• Speed Dial モード：お気に入りのサイトが、専用のブックマークフォルダ「Startiles Speed Dial」の中にタイルとして並び、グループごとに整理されます。
• ブックマークモード：ご自身のブックマーク（ブックマークバーまたは選択した任意のフォルダ）をビジュアルなタイルボードとして表示します。最上位のフォルダはグループになり、入れ子のフォルダはなめらかにアニメーションするウィンドウとして開きます。コピーされることも、拡張機能内に閉じ込められることもありません。ここでタイルの名前変更、移動、削除を行うと実際のブックマークが変更されます。一方、Speed Dial モードではご自身のブックマークには一切触れません。

どのブックマークもすぐに見つかる
検索エンジンに「ブックマーク」を選ぶと、入力するそばから、すべてのグループとフォルダのタイルがタイトルまたはアドレスで絞り込まれます。Enter で最初の一致を開き、Esc でクリアします。ウェブ検索が好みなら、お気に入りの検索エンジンを新しいタブからそのまま使えます（検索候補の表示は任意）。アドレスを入力または貼り付けると、そのまま開きます。

必要なものがすべて揃っています
• グループバー、フォルダ、入れ子のフォルダ。
• ドラッグ＆ドロップ：タイルの並べ替え、タイルを別のタイルにドロップしてフォルダを作成、グループのタブにドロップして移動。
• サムネイルは思いのまま：サイトのアイコン（複数のサイズから選択可能）、横長のサイトロゴ、ページのプレビュー、アイテム自体のカバー（動画、映画、ゲーム、本、商品がそれぞれの画像を表示）、またはご自身の画像やファイル。
• 複数のタイルをまとめて選択（タイルを長押し）：移動、開く、削除、さらにタイトルのスタイル、サムネイルモード、カバーのフィット方法をすべてのタイルで一度に変更できます。
• 削除後の取り消し（Ctrl+Z）：タイルとフォルダが元の場所に戻ります。
• テーマ：ライト、ダーク、ミッドナイト、サンド、自動（ブラウザに合わせる）、または独自のテーマを作成。
• レイアウトを細かく調整：タイルのサイズ、縦横比、角の大きさ、間隔、列数、オフセット、設定アイコンの位置。
• なめらかなアニメーション。7 種類のタイル削除エフェクトと、多数のタイルを一度に削除するときの軽めのエフェクトを搭載。システムの「視差効果を減らす」設定を尊重します。
• 完全なキーボード操作に対応し、Startiles を開くキーボードショートカットも自由に設定できます。
• 13 言語に対応。既定ではブラウザの言語に従います。
• 設定、テーマ、タイルのバックアップをエクスポート／インポート。インポートでは HTML 形式のブックマークファイルや、他の speed dial 拡張機能のエクスポートも読み込めます。

データはあなたのもの
タイルは通常のブラウザのブックマークなので、ブラウザのブックマーク同期を使っていれば、それに従って同期されます。アカウント不要、広告なし。Startiles 独自のサーバーはなく、分析データも送信しません。

サムネイルを作成するために接続するのは、タイルに必要な先だけです。アイコンサービス、追加したウェブサイト（アイコンとプレビュー画像を読み取るため）、カバーを表示するサイトのサービス（例：YouTube）、そして選択した検索エンジンです。オンラインのスクリーンショットサービスは既定でオフで、有効にした場合にのみ使われます。任意のオンラインロゴ検索（Wikidata と Wikimedia Commons）は、そのボタンを押したときだけ実行されます。アイコンやプレビューの取得、検索候補は「詳細設定」でオフにできます。

はじめに
新しいタブを開いてください。初回起動時に、Startiles が使い方を尋ねます。Speed Dials（専用フォルダを使用、ブックマークには触れません）か、ブックマーク（任意のブックマークフォルダを選択し、検索はすぐに「ブックマーク」に設定されます）のどちらかです。選択はいつでも「詳細設定」で変更できます。「+ ショートカット」をクリックしてサイトを追加しましょう。
