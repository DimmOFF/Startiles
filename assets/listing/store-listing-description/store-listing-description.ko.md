Chrome 북마크를 맞춤 설정할 수 있는 시각적 대시보드로 바꿔 보세요. Speed Dial과 기존 북마크를 오가며 사용하고, 모든 폴더에서 제목이나 URL로 검색하고, 링크를 그룹으로 정리하고, 아이콘, 페이지 미리보기, 항목 커버, 나만의 이미지로 타일을 꾸밀 수 있습니다.

계정이 필요 없습니다. 광고도 없습니다. 자체 북마크 저장소도 없습니다. 북마크는 Chrome에 그대로 남습니다.

기존 북마크 모음을 처음부터 다시 만들지 않고도 빠르고 맞춤 설정이 가능한 새 탭 페이지를 원하는 분께 안성맞춤입니다.

두 가지 모드, 클릭 한 번으로 전환
• Speed Dial 모드: 즐겨 찾는 사이트가 전용 북마크 폴더 'Startiles Speed Dial'에 타일로 담기고, 그룹별로 정리됩니다.
• 북마크 모드: 내 북마크(북마크바 또는 선택한 아무 폴더)를 시각적인 타일 보드로 보여 줍니다. 최상위 폴더는 그룹이 되고, 하위 폴더는 부드럽게 움직이는 창으로 열리며, 아무것도 복사되거나 확장 프로그램 안에 갇히지 않습니다. 여기서 타일의 이름을 바꾸거나 옮기거나 삭제하면 실제 북마크가 바뀝니다. 반면 Speed Dial 모드는 내 북마크를 전혀 건드리지 않습니다.

어떤 북마크든 바로 찾기
검색엔진으로 '북마크'를 선택하면 입력하는 즉시 모든 그룹과 폴더의 타일이 제목 또는 주소로 필터링됩니다. Enter를 누르면 첫 번째 일치 항목이 열리고, Esc를 누르면 입력이 지워집니다. 웹 검색을 선호하시나요? 새 탭에서 바로 즐겨 쓰는 검색엔진을 사용할 수 있고, 검색어 추천은 선택 사항입니다. 주소를 입력하거나 붙여 넣으면 바로 열립니다.

필요한 기능을 모두 갖췄습니다
• 그룹 막대, 폴더, 하위 폴더.
• 드래그 앤 드롭: 타일 순서 변경, 타일을 다른 타일 위에 놓아 폴더 만들기, 그룹 탭 위에 놓아 이동하기.
• 원하는 방식의 썸네일: 사이트 아이콘(여러 크기 중 선택), 넓은 사이트 로고, 페이지 미리보기, 항목 자체의 커버(동영상, 영화, 게임, 책, 상품이 각자의 이미지를 표시), 또는 내 이미지나 파일.
• 여러 타일을 한 번에 선택(타일을 길게 누르기): 이동, 열기, 삭제를 하거나 모든 타일의 제목 스타일, 썸네일 모드, 커버 맞춤 방식을 한 번에 바꿀 수 있습니다.
• 삭제 후 실행 취소(Ctrl+Z): 타일과 폴더가 원래 자리로 돌아옵니다.
• 테마: 라이트, 다크, 미드나이트, 샌드, 자동(브라우저를 따름), 또는 직접 만든 테마.
• 레이아웃 완전 제어: 타일 크기, 비율, 모서리 크기, 간격, 열 수, 오프셋, 설정 아이콘 위치.
• 부드러운 애니메이션: 7가지 타일 삭제 효과와 많은 타일을 한꺼번에 삭제할 때의 가벼운 효과를 제공합니다. 시스템의 '동작 줄이기' 설정을 존중합니다.
• 완전한 키보드 탐색과 Startiles를 여는 단축키(원하는 키로 지정 가능).
• 13개 언어로 제공됩니다. 기본적으로 브라우저 언어를 따릅니다.
• 설정, 테마, 타일의 백업을 내보내고 가져올 수 있습니다. 가져오기에서는 HTML 북마크 파일과 다른 speed dial 확장 프로그램의 내보내기 파일도 읽습니다.

내 데이터는 내 것입니다
타일은 일반 브라우저 북마크이므로, 브라우저의 북마크 동기화를 사용 중이라면 그대로 동기화됩니다. 계정 없음, 광고 없음. Startiles에는 자체 서버가 없으며 분석 데이터도 전송하지 않습니다.

썸네일을 만들기 위해 타일에 필요한 곳에만 연결합니다. 아이콘 서비스, 내가 추가한 웹사이트(아이콘과 미리보기 이미지를 읽기 위해), 커버를 보여 주는 사이트의 서비스(예: YouTube), 그리고 내가 선택한 검색엔진입니다. 온라인 스크린샷 서비스는 기본적으로 꺼져 있으며 직접 켠 경우에만 사용됩니다. 선택 사항인 온라인 로고 검색(Wikidata 및 Wikimedia Commons)은 해당 버튼을 눌렀을 때만 실행됩니다. 아이콘 및 미리보기 조회와 검색어 추천은 '고급 설정'에서 끌 수 있습니다.

시작하기
새 탭을 여세요. 처음 시작하면 Startiles가 사용 방식을 묻습니다. Speed Dials(전용 폴더 사용, 내 북마크는 그대로 유지) 또는 북마크(원하는 북마크 폴더를 선택하면 검색엔진이 곧바로 '북마크'로 설정됨) 중에서 고르세요. 언제든 '고급 설정'에서 바꿀 수 있습니다. '+ 바로가기'를 눌러 사이트를 추가하세요.
