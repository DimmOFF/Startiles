把你的 Chrome 书签变成可自定义的可视化仪表板。在 Speed Dial 与现有书签之间自由切换，按标题或网址搜索所有文件夹，将链接整理成分组，并用图标、页面预览、项目封面和自定义图片个性化磁贴。

无需账户。没有广告。没有专有的书签存储。你的书签始终留在 Chrome 中。

非常适合想要一个快速、可自定义的新标签页，又不想重新整理已有书签收藏的用户。

两种模式，一键切换
• Speed Dial 模式：你喜爱的网站会以磁贴形式存放在专用书签文件夹“Startiles Speed Dial”中，并按分组排列。
• 书签模式：将你自己的书签（书签栏或你选择的任意文件夹）显示为可视化磁贴看板。顶层文件夹变成分组，嵌套文件夹以流畅的动画窗口打开，不会复制任何内容，也不会把任何内容锁在扩展程序里。在这里重命名、移动或删除磁贴会修改你真实的书签，而 Speed Dial 模式不会动你自己的书签。

即刻找到任何书签
将“书签”选为搜索引擎后，所有分组和文件夹中的磁贴会在你输入时按标题或地址实时筛选。按 Enter 打开第一个匹配项，按 Esc 清除。更喜欢网页搜索？可直接在新标签页使用你常用的搜索引擎，还可选择开启搜索建议。输入或粘贴网址即可直接打开。

你需要的一切
• 分组栏、文件夹和嵌套文件夹。
• 拖放：重新排列磁贴；将一个磁贴拖到另一个磁贴上可创建文件夹；拖到分组标签上可将其移入该分组。
• 缩略图随你定：网站图标（有多种尺寸可选）、宽幅网站标志、页面预览、项目自身的封面（视频、电影、游戏、图书或商品会显示各自的图片），或你自己的图片或文件。
• 一次选中多个磁贴（长按磁贴）：移动、打开、删除，或一步更改所有磁贴的标题样式、缩略图模式和封面适配方式。
• 删除后可撤销（Ctrl+Z）：磁贴和文件夹会回到原来的位置。
• 主题：浅色、深色、午夜、沙色、自动（跟随浏览器），或创建你自己的主题。
• 全面掌控布局：磁贴大小、比例、圆角大小、间距、列数、偏移量、设置图标位置。
• 流畅的动画，包括 7 种磁贴删除效果，以及批量删除多个磁贴时使用的轻量效果。尊重系统的“减少动态效果”设置。
• 完整的键盘导航，以及可自行设定的打开 Startiles 的键盘快捷键。
• 支持 13 种语言，默认跟随浏览器的语言。
• 导出和导入设置、主题与磁贴的备份。导入时还能读取 HTML 书签文件以及其他 speed dial 扩展程序的导出文件。

你的数据始终属于你
磁贴就是普通的浏览器书签，因此如果你使用浏览器自带的书签同步，它们会随之同步。无需账户，没有广告。Startiles 没有自己的服务器，也不发送任何分析数据。

为了生成缩略图，它只会联系磁贴所需的对象：图标服务、你添加的网站（用于读取其图标和预览图）、它所展示封面的网站所用的服务（例如 YouTube），以及你选择的搜索引擎。在线截图服务默认关闭，只有在你开启后才会使用。可选的在线标志搜索（Wikidata 和 Wikimedia Commons）仅在你点击其按钮时运行。你可以在“高级设置”中关闭图标和预览查询以及搜索建议。

开始使用
打开一个新标签页。首次启动时，Startiles 会询问你想如何使用：Speed Dials（使用专属文件夹，你的书签保持原样）或书签（选择任意书签文件夹，搜索引擎会立即设为“书签”）。你可以随时在“高级设置”中更改。点击“+ 快捷方式”即可添加网站。
